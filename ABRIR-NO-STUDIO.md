# Abrir a build atual

Baixe o ZIP do repositório e abra **releases/Feras-Tester.rbxlx**. Confira o roteiro no README.md. Os outros dois arquivos de releases são aliases atualizados.

Para recompilar: `rojo build -o Feras-Tester.rbxlx`. Para meshes importados, leia IMPORTAR-MODELOS.md; arquivos OBJ na pasta de autoria não são enviados automaticamente ao Roblox.
